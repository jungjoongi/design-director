# 섹션 타입 레지스트리

페이지를 이루는 섹션의 이름표. `ref` 의 페이지 구조(7장), `direct` 의 구조 설계, 엔진의 자동 분류가 **같은 id** 를 쓴다.
새 id 를 만들지 말고 여기서 고른다. 맞는 게 없으면 가장 가까운 id 에 변형을 메모한다. 반복해서 필요한 id 는 메인테이너가
이 파일에 추가한다(설치된 플러그인 파일은 고치지 않는다).

- **감지** ✓ = 엔진(`dd.mjs analyze`)이 자동으로 붙일 수 있는 id. 나머지는 Claude 가 스크린샷·코드를 보고 붙인다.
- 와이어프레임 박스 안 라벨은 id 를 그대로 쓴다(영문이라 터미널 정렬이 깨지지 않는다).

## 목차
1. 마케팅·랜딩
2. 앱(SaaS) 화면
3. 커머스
4. 커뮤니티
5. 콘텐츠·포트폴리오
6. 레이아웃 패턴 (스타일 아님)

## 6. 레이아웃 패턴 (스타일 아님)

벤토·분할·풀블리드는 **스타일이 아니라 배치 방식**이다. "벤토 스타일로" 라는 요청은 `bento-grid` 섹션 + 기본 스타일 하나로 번역한다.

| 패턴 | 뜻 | 대응 id |
|---|---|---|
| bento | 크기가 다른 타일의 격자 | `bento-grid` |
| split | 좌우 분할 | `hero-split`, `media-text` |
| alternating | 좌우 교대 행 | `feature-alternating` |
| full-bleed | 화면 가장자리까지 꽉 찬 배경·이미지 | `hero-media`, 섹션 변형 메모 |
| masonry | 높이가 다른 카드를 벽돌처럼 | `gallery` 변형 |
| sticky-scrollytelling | 한쪽이 고정되고 스크롤로 내용이 바뀜 | `feature-alternating` 변형 메모 |
