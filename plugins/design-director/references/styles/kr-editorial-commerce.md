# 29CM형 에디토리얼 커머스 (KR Editorial Commerce) — id: kr-editorial-commerce

별칭: 29CM 느낌, 감성 커머스, 매거진형 쇼핑몰, 편집숍 느낌, 큐레이션 커머스
축: 밀도 2 · 온도 3 · 채도 1 · 대비 4 · 둥긂 1 · 장식 2
대표 레퍼런스: 29CM (29cm.co.kr), 무신사 (musinsa.com) 의 매거진 영역 (정성, 미검증)

## 정의

상품을 "목록"이 아니라 "이야기"로 판다. 크고 가장자리까지 찬 상품·룩북 사진, 작고 절제된 글자(12–14px), 흑백 UI 로
**사진이 색을 독점**하게 한다. 잡지처럼 기획전·인터뷰·브랜드 스토리가 상품 그리드 사이에 끼어들고, 여백이 넉넉하다.

이웃과의 차이: luxury 는 상품 목록과 가격을 숨기고, 이 스타일은 커머스 관례(할인율·가격·리뷰 수)를 지키면서 조용하게 보여준다.
editorial 은 글이 주인공이고, 이 스타일은 사진이 주인공이다.

## 시그니처 무브

1. **사진이 색을 독점한다** — UI 는 무채색만, 유채색은 상품 사진과 할인율에만.
2. **글자를 작고 단정하게** — 상품명 12–14px, 위계는 크기보다 굵기와 색(검정 / 회색)으로.
3. **사진을 가장자리까지** — 기획전 이미지는 풀블리드, radius 0, 이미지 사이 gap 0–2px.
4. **상품 사이에 이야기를 끼운다** — 상품 8–16개마다 기획전·인터뷰 섹션이 그리드를 끊는다.
5. **가격은 관례대로, 조용하게** — 할인율 빨강 굵게 → 판매가 굵게 → 정가 회색 취소선, 한 줄.

## 잘 맞는 곳 / 안 맞는 곳

- 잘 맞는 곳: 패션·라이프스타일 커머스, 편집숍, 브랜드 자사몰, 리빙·인테리어, 큐레이션 서비스, 매거진 + 커머스.
- 안 맞는 곳: 생필품·최저가 커머스(가격 비교가 먼저), 앱 기능 화면, 사진 품질이 약한 상품군.

## 흔한 실수

- 상품 이미지 비율이 제각각이라 그리드가 무너진다. 3:4 나 4:5 하나로 통일한다.
- UI 에 브랜드 색을 넓게 써서 사진과 경쟁한다 — 색이 늘면 CO-5
- 스톡 사진, AI 생성 이미지의 결함 — IC-4, IC-5
- 할인율·정가 취소선·무료배송·리뷰 수 같은 한국 커머스 관례를 뺀다 — KR-6
- 모든 섹션 fade-up — MO-1

## 한국어 노트

- 상품명은 2줄 말줄임(`display: -webkit-box; -webkit-box-orient: vertical; -webkit-line-clamp: 2; overflow: hidden;`, Tailwind 는
  `line-clamp-2`), 그 위에 브랜드명을 작고 굵게.
- 가격 표기: "39,000원", 할인율 "20%"를 앞에 빨강 굵게, 정가는 취소선.
- 글자가 작은 스타일이라 한글 하한이 더 중요하다. 상품명 12px 아래로 내리지 않고, 가능하면 13px.
- 기획전 카피는 짧은 명사구나 문장 하나. 번역투 문장을 피한다(KR-7).
- 상세 페이지는 긴 상세 이미지(`detail-images`)가 관례지만, 소재·사이즈 같은 핵심 정보는 텍스트로도 쓴다.
