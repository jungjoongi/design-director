# 한국형 관리자 (KR Classic Admin) — id: kr-admin-classic

별칭: 한국형 어드민, 관리자 페이지, 백오피스 기본형, 쇼핑몰 관리자, 솔루션 관리자 화면, 검색 조건 박스, SI 관리자, 그리드 화면
축: 밀도 5 · 온도 2 · 채도 3 · 대비 3 · 둥긂 1 · 장식 1
대표 레퍼런스: 국내 쇼핑몰 솔루션 관리자 화면 계열, 국내 SI·그룹웨어 백오피스 계열, 공공기관 업무 시스템 계열 (정성, 미검증)

## 정의

국내 백오피스에서 오래 굳은 문법을 그대로 따르는 화면이다. 위에 회색(또는 남색) 헤더 바, 왼쪽에 트리 메뉴,
본문은 **검색 조건 박스 → 검색·초기화 버튼 → 결과 건수·엑셀 다운로드·일괄 처리 버튼 → 테두리 그리드 표 → 페이지네이션**
순서로 내려온다. 운영자가 이미 손에 익힌 배치라 새로 배울 게 없다는 점이 이 스타일의 가치다. 장식은 없고,
모든 칸에 테두리가 있어 어디가 입력이고 어디가 값인지 헷갈리지 않는다.

이웃과의 차이: data-dense 는 필터를 한 줄 바와 칩으로 접고 행 구분선 하나로 정리한다. kr-admin-classic 은 검색 조건을
회색 라벨 셀 + 입력 셀의 표 격자로 펼치고, 그리드 표도 세로선까지 모두 긋는다. 축은 비슷해도 구조가 다르다.
admin-calm 은 비전문가를 위해 여유를 두고, kr-admin-classic 은 숙련 운영자가 한 화면에서 조회·처리를 끝내게 한다.

## 시그니처 무브

1. **검색 조건 박스** — 회색 라벨 셀(폭 110–140px, 13px 600) | 입력 셀의 2–4열 격자. 기간 행에는
   날짜 2개 + `오늘 · 7일 · 1개월 · 3개월 · 전체` 버튼 묶음. 박스 아래 가운데에 `검색`(채움) · `초기화`(테두리).
2. **결과 머리줄** — 왼쪽 `총 1,284건` (숫자만 강조색), 오른쪽 `목록 개수 20/50/100 셀렉트` · `엑셀 다운로드` · 일괄 처리 버튼.
3. **전부 그은 그리드** — 회색 헤더 행, 모든 셀 1px, 첫 열 체크박스(전체 선택), 번호 열, 가운데 정렬 코드·상태 열, 오른쪽 정렬 금액 열.
4. **숫자 페이지네이션** — `« ‹ 1 2 3 … 10 › »`, 현재 페이지는 채운 사각.
5. **좌측 트리 메뉴** — 대분류(굵게) 아래 중분류 들여쓰기, 현재 메뉴는 배경 + 왼쪽 막대.

## 잘 맞는 곳 / 안 맞는 곳

- 잘 맞는 곳: 쇼핑몰 회원·주문·상품 관리, 사내 업무 시스템, 정산·CS 처리, 공공·금융 백오피스, 기존 관리자의 리뉴얼(관례 유지가 조건일 때).
- 안 맞는 곳: 소규모 사업자용 쉬운 관리자(admin-calm), 실시간 관제(admin-console), 해외 사용자 대상 SaaS, 모바일 우선 화면.

## 흔한 실수

- 검색 조건 박스를 "모던하게" 칩·카드로 바꿔 숙련 운영자의 손을 끊는다 — KR-6
- 그리드를 둥근 카드 목록으로 바꾼다 — KR-6, LA-1
- 회색 라벨 셀 글자를 옅게 — CO-7
- 버튼마다 다른 색(파랑·초록·주황·보라·빨강) — CO-5. 주 버튼 1색 + 엑셀 초록 + 위험 빨강 테두리까지만.
- 코드·전화번호·이메일 열까지 모노스페이스 — TY-5
- 한글 웹폰트 없이 OS 기본 폰트로 — KR-2. 관리자 화면이 가장 자주 빠뜨린다.
- `keep-all` 없이 좁은 열에서 이름·상품명이 음절 단위로 끊긴다 — KR-1

## 한국어 노트

- 관례 용어를 그대로 쓴다: `검색`, `초기화`, `엑셀 다운로드`, `선택 삭제`, `일괄 변경`, `목록 개수`, `총 n건`. 바꾸면 오히려 찾기 어렵다.
- 기간 버튼 순서는 짧은 것부터 `오늘 · 7일 · 1개월 · 3개월 · 6개월 · 전체`. 선택된 버튼은 채운 색으로.
- 날짜는 `2026-10-15` 또는 `2026.10.15`, 일시는 `2026-10-15 14:32`. 한 화면에서 한 형식만.
- 개인정보는 목록에서 마스킹한다: `김*진`, `010-****-5678`, `ab***@mail.com`. 상세에서만 전체를 보여준다.
- 회원 등급·상태는 텍스트 배지(`일반`, `VIP`, `휴면`, `탈퇴`)로 쓰고 색만으로 구분하지 않는다.
- 엑셀 다운로드는 "개인정보 다운로드 사유 입력" 모달이 따라오는 경우가 많다. 버튼 옆에 작게 안내한다.
- 그리드가 가로로 넘치면 가로 스크롤을 허용하고 체크박스·번호·이름 열을 고정한다.
