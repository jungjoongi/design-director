# 코퍼릿 클린 (Corporate Clean) — id: corporate-clean

별칭: 기업형, 신뢰감 있는, 엔터프라이즈, B2B SaaS 스타일, 깔끔한 기업 사이트
축: 밀도 3 · 온도 2 · 채도 3 · 대비 3 · 둥긂 3 · 장식 2
대표 레퍼런스: Stripe (stripe.com)의 정돈된 정보 구조, IBM Carbon 디자인 시스템 계열 (정성, 미검증)

## 정의

신뢰와 명료함이 목표다. 정돈된 섹션, 브랜드 색 하나(주로 파랑·남색·청록 계열), 일관된 버튼·입력·카드 시스템, 실제 제품
화면과 출처 있는 고객 사례로 설득한다. 개성보다 일관성이 먼저다.

이 스타일은 "SaaS 카드 키트"(LA-1)로 가장 쉽게 무너진다. 그래서 위계를 카드 반복이 아니라 **섹션마다 다른 레이아웃**과
실제 화면의 크기로 만드는 게 관건이다.

## 시그니처 무브

1. **실제 제품 화면을 증거로 쓴다** — 히어로·기능 섹션마다 실제 UI 를 1:1 또는 확대 크롭으로. 기울인 3D 목업은 쓰지 않는다.
2. **브랜드 색을 행동에만 쓴다** — 주 CTA·링크·활성 상태에 한정, 면적 5–10%.
3. **섹션마다 레이아웃을 바꾼다** — split, 그리드, 교차 행, 표를 섞어 같은 골격 반복을 피한다(LA-3).
4. **숫자와 사례에 출처를 붙인다** — 고객사 이름·수치·인용 옆에 출처나 사례 링크.
5. **컴포넌트 상태를 모두 설계한다** — hover·focus·disabled·오류, `:focus-visible` 2px 링.

## 잘 맞는 곳 / 안 맞는 곳

- 잘 맞는 곳: B2B SaaS, 핀테크 기업 사이트, 채용, 공공·의료·교육 서비스, 문서·고객센터.
- 안 맞는 곳: 개성으로 승부하는 소비자 브랜드, 패션·뷰티, 크리에이터 포트폴리오.

## 흔한 실수

- 모든 정보를 같은 둥근 카드와 같은 그림자에 담는다 — LA-1, SH-1, SH-2
- 아이콘 + 제목 + 설명 3열만 반복하고, 아이콘은 모두 옅은 둥근 사각 위에 — LA-2, IC-2
- 보라→파랑 그라데이션 히어로 — CO-1. 큰 숫자 통계를 기본 히어로로 — LA-6
- 지어낸 고객 로고·후기·수치 — CP-5
- "Get Started" + "Learn More" 버튼 쌍 — CP-6. 버튼 끝 화살표 — CP-1

## 한국어 노트

- 한국 B2B 페이지의 관례: 도입 문의 폼, 고객사 로고, 보안 인증 배지, 사업자 정보 푸터(KR-6). 없는 인증은 만들지 않는다.
- 번역투 카피를 피한다. "혁신적인 솔루션을 경험하세요" 대신 "회의록을 5분 안에 공유해요" 처럼 동사와 숫자로 쓴다(KR-7).
- 버튼은 무슨 일이 일어나는지 말한다: "도입 문의하기", "무료로 시작하기".
- 표·요금의 숫자는 `tabular-nums`, 원화는 천 단위 쉼표 + "원".
