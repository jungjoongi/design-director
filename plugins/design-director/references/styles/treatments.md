# 트리트먼트 (Treatments)

트리트먼트는 스타일이 아니라 기본 스타일 위에 얹는 **표면 처리**다. 프로필·브리프에는 primary 스타일 하나에 0–2개만 붙인다
(표기: `dark-tech + glassmorphism`). 다섯 가지 모두 2020년대 AI 생성 화면에 습관처럼 등장해서, 조건 없이 쓰면 바로
AI 기본값 패턴으로 읽힌다. 그래서 블록마다 "필요한 조건"과 "무너지면"을 먼저 본다.

| id | 한 줄 | 무너지면 |
|---|---|---|
| `glassmorphism` | 뒤를 흐리는 반투명 면 | SH-3 |
| `neumorphism` | 배경과 같은 색 면을 양방향 그림자로 돌출 | SH-4 |
| `aurora-gradient` | 흐린 다색 그라데이션 면 | CO-4 (+ CO-1) |
| `grain-noise` | 미세 입자 질감 한 겹 | 대응 ID 없음 |
| `clay-3d` | 무광 파스텔 3D 렌더 | IC-3 |

## glassmorphism (글래스모피즘)

- **정의**: 뒤 콘텐츠를 흐리는 반투명 면. 유리 너머로 색과 형태가 비치면서 층이 생긴다.
- **필요한 조건**: 면 뒤에 다색 배경·사진·움직이는 콘텐츠가 있어야 한다. 흰 단색 위의 글래스는 그냥 옅은 회색 카드다.
- **값 범위**
  - `backdrop-filter: blur(12–24px) saturate(120–180%)`
  - 채움: 라이트 흰색 알파 8–20%(떠 있는 패널) / 다크 흰색 알파 4–12%. 텍스트를 올리는 내비는 60–80% 로 불투명하게.
  - 테두리 1px 흰색 알파 15–30%, 상단 하이라이트 `inset 0 1px 0 rgb(255 255 255 / 0.2)`
- **무너지면 — SH-3**: 뒤에 비칠 것이 없는 곳, 모든 카드, 본문 텍스트 영역에 쓴다.
- **정당한 경우**: 사진·영상 위의 컨트롤, 히어로 이미지 위 sticky 내비, 지도 위 플로팅 패널, OS 같은 메뉴·툴바.
- **주의**: 뒤 배경이 바뀌면 텍스트 대비도 바뀐다. 가장 밝은 배경 위에서 4.5:1 을 확인하고, 모자라면 채움을 올린다.
  큰 면적의 `backdrop-filter` 는 모바일에서 무겁다. 미지원 브라우저용 불투명 폴백을 둔다.
- **프롬프트**: "히어로 사진 위 sticky 내비에만 글래스: blur 16px, 흰 70%, 하단 1px 흰 20% 경계. 카드에는 쓰지 않는다." /
  "Glass only on the sticky nav over the hero photo: 16px blur, 70% white fill, 1px white-20% bottom border. Never on cards."

## neumorphism (뉴모피즘)

- **정의**: 배경과 같은 색의 면을 밝은 그림자(위·왼쪽)와 어두운 그림자(아래·오른쪽)로 부풀리거나 눌러 보이게 한다.
- **필요한 조건**: 배경과 면이 같은 중간 명도(명도 85–94%)여야 효과가 난다. 흰색·검정 배경에선 성립하지 않는다.
- **값 범위**
  - 그림자 오프셋 ±6–12px, blur 12–24px
  - 밝은 쪽 흰색 알파 60–90%, 어두운 쪽 배경보다 명도 10–15% 낮은 같은 hue(또는 검정 알파 8–18%)
  - radius 12–24px, 눌린 상태는 같은 값의 `inset` 그림자
- **무너지면 — SH-4**: 버튼·입력·토글 같은 컨트롤에 쓴다. 경계 대비가 1.1:1 안팎이라 무엇을 누를 수 있는지,
  지금 눌린 상태인지 보이지 않는다(WCAG 1.4.11 비텍스트 대비 3:1 미달).
- **정당한 경우**: 누르지 않는 장식 요소, 실물 기기를 흉내 낸 화면(오디오 앱의 다이얼)에서 텍스트 라벨·포커스 링·
  색 변화로 상태를 따로 보강할 때.
- **프롬프트**: "뉴모피즘은 장식 카드 하나에만. 버튼·입력은 일반 스타일로, 대비 3:1 이상 테두리." /
  "Neumorphism on one decorative card only; buttons and inputs stay conventional with 3:1+ borders."

## aurora-gradient (오로라 그라데이션)

- **정의**: 크게 흐린 다색 그라데이션이나 mesh gradient 로 만든 빛·대기 같은 배경.
- **필요한 조건**: 색이 브랜드 hue 에서 와야 한다. 기본 보라→파랑을 고르면 CO-1 이다. 위에 올라가는 텍스트의 대비를 지킨다.
- **값 범위**
  - 2–4색, 인접 hue(hue 폭 90–120° 이내), 채도는 브랜드색보다 한 단계 낮게
  - blur 60–160px 또는 mesh, 불투명도 30–70%
  - 면적: 히어로 한 곳이나 섹션 하나. 페이지 전체 배경으로 깔지 않는다.
  - 움직이면 10–30초 주기로 아주 느리게, `prefers-reduced-motion` 에서는 정지
- **무너지면 — CO-4**: 히어로 뒤에 습관처럼 블롭을 놓는다. 색이 보라·파랑이면 CO-1 까지 겹친다.
- **정당한 경우**: 색과 빛이 정체성인 브랜드, 음악·크리에이티브 도구, 제품 자체가 색을 다루는 경우.
- **프롬프트**: "히어로에만 브랜드 주황→분홍 2색 mesh gradient, 불투명도 50%, blur 120px, 움직임 없음." /
  "Hero only: a 2-color brand orange-to-pink mesh gradient at 50% opacity, 120px blur, static."

## grain-noise (그레인·노이즈)

- **정의**: 필름 입자 같은 미세 노이즈를 한 겹 얹어 평평한 디지털 색 면에 촉감을 준다.
- **필요한 조건**: 넓은 단색 면이나 그라데이션이 있어야 보인다. 그라데이션 banding(계단 현상)을 감추는 실용 효과도 있다.
- **값 범위**
  - 불투명도 3–8%, `mix-blend-mode: overlay` 또는 `multiply`
  - SVG `feTurbulence`(baseFrequency 0.6–0.9) 또는 128–256px 반복 타일
  - 고정 레이어: `position: fixed; inset: 0; pointer-events: none;`
- **무너지면**: 대응하는 ID 는 없다. 그러나 10% 넘게 올리면 화면이 더러워 보이고, 그라데이션 블롭(CO-4)을 그럴듯하게
  가리는 용도로 쓰면 결국 같은 기본값이다. 텍스트 위에 얹지 않는다.
- **정당한 경우**: organic-soft·editorial 의 종이 질감, 아날로그 감성 브랜드, 넓은 그라데이션의 banding 완화.
- **프롬프트**: "배경 전체에 그레인 4%, overlay, 고정 레이어. 텍스트 영역 위로는 올리지 않는다." /
  "A 4% grain overlay on the page background as a fixed layer; keep it out of text blocks."

## clay-3d (클레이 3D)

- **정의**: 점토처럼 무광이고 둥근 3D 렌더. 파스텔 색, 부드러운 그림자, 장난감 같은 비례.
- **필요한 조건**: 같은 조명 방향·카메라 각도·재질·팔레트로 만든 **고유 렌더 세트**. 서로 다른 팩의 3D 아이콘을 섞으면 바로 깨진다.
- **값 범위**
  - 팔레트 2–4색 파스텔(브랜드 hue 기반), 재질 무광, 그림자 아래쪽 부드럽게
  - 화면당 렌더 1개, 섹션당 최대 1개
  - 크기: 아이콘 용도 48–96px, 히어로 오브젝트 240–480px
- **무너지면 — IC-3**: 의미 없는 블롭·구·물방울을 빈자리마다 띄운다.
- **정당한 경우**: 렌더가 실제 개념을 나타낼 때(카드·동전·택배 상자·자물쇠), 핀테크·소비자 앱의 주제 그래픽, 온보딩 일러스트.
- **프롬프트**: "화면 주제를 나타내는 클레이 3D 오브젝트 1개(파스텔 2색, 무광, 조명 왼쪽 위). 장식용 구·블롭 금지." /
  "One clay-style 3D object per screen that depicts the screen's subject (2 pastels, matte, top-left light). No decorative spheres or blobs."
