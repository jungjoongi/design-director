# 동네 피드형 (KR Local Feed) — id: kr-local-feed

별칭: 동네 커뮤니티, 피드형 커뮤니티, 동네생활 같은, 지역 기반 피드, 관심사 피드, 근황 피드, local feed
축: 밀도 3 · 온도 4 · 채도 3 · 대비 3 · 둥긂 4 · 장식 2
대표 레퍼런스: 국내 지역 기반 생활 커뮤니티 피드 계열, 관심사 모임 앱 피드 계열 (정성, 미검증)

## 정의

사진과 짧은 근황이 중심인 피드다. 글 하나가 이미지 + 주제 칩 + 동네 이름 + 상대 시간 + 공감·댓글 수를 가진 카드가
되고, 사용자는 엄지로 가볍게 넘기며 "우리 동네 얘기"를 고른다. 따뜻한 중립 바탕에 강조색 하나, 둥근 모서리, 친절한
해요체가 재료다. 친근하지만 캐릭터·일러스트로 꾸미지 않는다 — 콘텐츠 사진이 온기를 만든다.

모바일 피드가 원형이고, 데스크톱에서는 가운데 피드 칼럼(560–680px) + 옆 정보 칼럼(동네 정보·인기 주제·모임)으로 넓힌다.

이웃과의 차이: playful-illustrative 는 고유 일러스트·탄성 모션으로 즐거움을 만들고, kr-local-feed 는 사용자 사진과
위치 정보로 친밀감을 만든다(장식 2). kr-board-classic 은 텍스트 행을 빠르게 훑고, kr-local-feed 는 카드 하나에 오래 머문다.

## 시그니처 무브

1. **글쓴이 줄에 동네와 상대 시간** — `닉네임 · 망원동 · 12분 전`, 동네 인증이면 작은 체크. 위치가 신뢰 단서다.
2. **주제 칩 가로 줄** — 전체·맛집·분실물·나눔·질문… 28–32px pill, 선택 칩만 진한 채움, 가로 스크롤.
3. **카드 아래 공감·댓글 수** — 아이콘 + 숫자 13px, 공감 활성일 때만 강조색. 조회는 메타 끝에 작게.
4. **글쓰기 FAB 56px** — 강조색 채움, 오른쪽 아래, 라벨 "글쓰기"는 스크롤하면 접는다.
5. **데스크톱은 가운데 피드 + 옆 정보** — 사이드에 내 동네·인기 주제·근처 모임. 피드 폭은 모바일 감각 그대로 680px 이하.

## 잘 맞는 곳 / 안 맞는 곳

- 잘 맞는 곳: 지역 생활 커뮤니티, 아파트·학교·캠퍼스 커뮤니티, 취미·반려동물·육아 모임, 근황·후기 피드.
- 안 맞는 곳: 긴 토론·정보 게시판(→ kr-board-classic), 질문·답 지식 커뮤니티(→ forum-thread), B2B·금융.

## 흔한 실수

- 이미지 없는 글에 회색 빈 박스·스톡 사진을 채운다 — IC-4. 텍스트 카드로 둔다
- 카드마다 같은 radius·그림자를 반복해 SaaS 카드 키트처럼 보인다 — LA-1, SH-2
- 강조색을 칩마다 다르게 칠한다 — CO-5
- 기능 아이콘을 이모지로(공감 하트·위치 핀) — IC-1
- 카드 등장 fade-up, hover-lift — MO-1, MO-2
- 글이 많은 정보 게시판까지 카드 피드로 바꾼다 — KR-6
- 캐릭터·일러스트를 넣어 성인 사용자에게 유치해 보인다(playful 과 섞임)

## 한국어 노트

- 시간은 상대 시간: "방금", "12분 전", "3시간 전", "어제", 일주일 넘으면 `10.08`.
- 동네 이름은 행정동보다 생활권 이름(`망원동`, `연남동`)이 자연스럽다. 인증 여부를 글쓴이 옆에.
- 반응 단어는 서비스에 맞게 하나로 통일한다: 공감·좋아요·도움돼요 중 하나.
- 카피는 해요체, 동네 이웃에게 말하듯 짧게: "우리 동네 이야기를 나눠 보세요", "근처 이웃에게 물어보세요".
- 무한 스크롤이면 글 상세에서 돌아올 때 위치를 복원한다(`community.md` §2.2).
