# 데이터 밀집 (Data-dense) — id: data-dense

별칭: 대시보드형, 정보 밀도 높은, 터미널 느낌, 파워 유저용, 엑셀 같은, 게시판형
축: 밀도 5 · 온도 2 · 채도 2 · 대비 3 · 둥긂 2 · 장식 1
대표 레퍼런스: 금융 터미널·트레이딩 화면, Hacker News (news.ycombinator.com), 한국 커뮤니티 게시판 목록 (정성, 미검증)

## 정의

한 화면에 최대한 많은 정보를 **훑어볼 수 있게** 놓는다. 작은 글자, 촘촘한 행, 정렬된 숫자, 최소한의 장식이 재료다.
위계는 크기가 아니라 색·굵기·위치·정렬로 만든다. 자주, 오래 보는 화면에서는 효율이 곧 미학이다.

이웃과의 차이: corporate-clean 은 여유 있는 행과 카드로 설명하고, data-dense 는 표와 행으로 비교하게 한다.

## 핵심 레버 (범위)

범위만 준다(이유는 `_index.md` §3).

| 레버 | 범위 | 메모 |
|---|---|---|
| 서체 | x-height 가 큰 산세리프 1 패밀리, 숫자는 `tabular-nums` | 모노스페이스는 코드·ID 에만(TY-5) |
| 크기 | 본문 13–14px, 표 12–14px, 라벨 11–12px, 화면 제목 16–20px | 단계가 좁다(비율 1.067–1.125) |
| 행간 | 본문 1.5, 표 셀만 1.35–1.4 | 한글 본문은 1.5 아래로 내리지 않는다(`korean-typography.md` §2) |
| 행 높이 | 표 32–36px(밀집) / 40–44px(보통) | |
| 색 구조 | 무채색 바탕, 의미색(상승·하락·경고)이 주인공, 브랜드 색은 선택·활성에만 | |
| 대비 | 텍스트 4.5:1 이상, 구분선 1.1–1.3:1 | 작은 글자일수록 대비를 지킨다 |
| radius | 2–6px | |
| 테두리 | 1px 행 구분선 또는 zebra 줄무늬 중 하나 | 둘 다 쓰면 시끄럽다 |
| 그림자 | 없음(팝오버·메뉴만 1단계) | |
| 간격 | 4px 기준, 셀 padding 8–12px, 패널 gap 8–16px | |
| 레이아웃 | 사이드바 200–240px + 다중 패널, 고정 헤더, 가로 스크롤 표 | |
| 밀도 | 첫 화면 빈 칸 30% 미만 | |
| 모션 | 0–150ms, 데이터 갱신 하이라이트만 | |
| 이미지 | 거의 없음. 차트·스파크라인 | |
| 아이콘 | 16px 선 아이콘, 의미가 있는 곳에만 | |

## 시그니처 무브

1. **숫자를 오른쪽 정렬, 고정폭으로** — `font-variant-numeric: tabular-nums`, 단위는 열 머리에 한 번만.
2. **행을 촘촘하게, 구분은 선 하나로** — 행 32–36px, 1px 구분선, 셀 padding 좌우 12px.
3. **색은 의미에만 쓴다** — 상승·하락·경고·선택 말고는 무채색.
4. **요약에서 상세로 쌓는다** — 위에 지표 줄(kpi-row), 가운데 필터 바(filter-bar, 고정), 아래 표(data-table).
5. **작은 글자도 대비를 지킨다** — 11–12px 라벨도 4.5:1 이상.

## 잘 맞는 곳 / 안 맞는 곳

- 잘 맞는 곳: 대시보드, 어드민, 분석 도구, 트레이딩, 게시판 목록, 개발자 도구 설정 화면.
- 안 맞는 곳: 마케팅 랜딩의 첫 화면, 감성 브랜드, 초보 사용자 온보딩.

## 흔한 실수

- 지표를 똑같은 둥근 카드로 반복한다 — LA-1
- 데이터 라벨을 모노스페이스로 — TY-5
- 옅은 회색 본문 — CO-7. 13px 에서는 치명적이다.
- 게시판 목록을 카드 피드로 바꿔 훑어보기가 죽는다 — KR-6
- 질문 없는 차트를 장식으로 넣는다. 차트마다 답하는 질문을 제목으로 쓴다.

## 한국어 노트

- 한국 커뮤니티 게시판 목록 관례: 번호·말머리·제목[댓글수]·글쓴이·시간·조회·추천(KR-6).
- 한국 금융 색은 서양과 반대다: 상승 빨강, 하락 파랑.
- 한글은 13px 아래에서 획이 뭉친다. 한글 표 본문 13–14px, 라벨 12px 을 하한으로 둔다.
- 시간은 "3분 전", "어제", "10.14" 처럼 상대 시간과 짧은 날짜를 섞는다.
- 금액은 천 단위 쉼표 + "원", 큰 금액은 "만·억" 단위를 쓴다.
