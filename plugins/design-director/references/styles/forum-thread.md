# 스레드형 포럼 (Threaded Forum) — id: forum-thread

별칭: 포럼, Q&A 포럼, 지식 커뮤니티, 토론 포럼, 개발자 커뮤니티, 질문 답변 사이트, threaded forum, discussion forum
축: 밀도 4 · 온도 1 · 채도 2 · 대비 3 · 둥긂 2 · 장식 1
대표 레퍼런스: 글로벌 개발자 Q&A 사이트 계열, 오픈소스 토론 포럼 계열 (정성, 미검증)

## 정의

글 하나를 깊게 파는 지식 커뮤니티다. 목록은 투표 수·답변 수·조회 수 열과 태그로 "좋은 질문"을 고르게 하고,
글 상세는 질문 → 채택 답변 → 다른 답변 → 들여쓰기 선으로 이어지는 답글 트리로 논의를 쌓는다. 차가운 회청색 중립,
작은 radius, 장식 없음. 정보가 먼저고, 위계는 투표 수와 채택 표시가 만든다.

이웃과의 차이: kr-board-classic 은 많은 글을 시간순으로 훑고(대댓글 1단계), forum-thread 는 적은 글을 점수순으로
깊게 읽는다(답글 트리 3–4단계). data-dense 는 숫자를 비교하고, forum-thread 는 글과 코드를 읽는다.

## 시그니처 무브

1. **왼쪽 세로 투표 열** — ▲ 점수 ▼ 를 글·답변마다 왼쪽에, 점수 tabular-nums, 내가 누른 방향만 파랑.
2. **채택 답변을 맨 위에 초록으로** — 체크 + "채택된 답변" 라벨 + 왼쪽 초록 선. 점수가 더 높은 답이 있어도 채택이 위.
3. **들여쓰기 선이 있는 답글 트리** — 단계당 20px 안팎 + 1px 세로 선, 3–4단계 뒤에는 접는다.
4. **목록의 숫자 세 칸** — 투표·답변·조회를 제목 왼쪽에 세로 숫자 블록으로. 채택된 질문은 답변 칸을 초록 테두리로.
5. **카테고리 사이드바 + 태그** — 왼쪽에 카테고리(글 수 포함), 제목 아래 태그 칩 2–5개.

## 잘 맞는 곳 / 안 맞는 곳

- 잘 맞는 곳: 개발자·기술 Q&A, 제품 사용자 포럼, 오픈소스 토론, 학습 커뮤니티, 사내 지식 공유.
- 안 맞는 곳: 근황·사진 피드(→ kr-local-feed), 빠르게 흘러가는 잡담 게시판(→ kr-board-classic), 마케팅 랜딩.

## 흔한 실수

- 답글 트리를 6단계 이상 들여써서 본문이 한 글자 폭이 된다 — 3–4단계에서 접는다
- 질문 목록을 큰 카드 + 그림자로 — LA-1, SH-2
- 메타·태그·투표 숫자까지 모노스페이스로 — TY-5
- 옅은 회색 답글 본문 — CO-7
- 채택 초록, 투표 주황, 태그 보라… 의미색을 늘린다 — CO-5
- 한국 일반 커뮤니티에 그대로 가져와 대댓글 1단계 관례를 깬다 — KR-6
- 코드 블록에 가짜 macOS 창 점 3개를 붙인다 — 장식만 늘고 정보는 없다

## 한국어 노트

- 국내 일반 커뮤니티는 게시판형·피드형이 기본이다(`community.md` §1.1). 스레드형은 지식·기술 커뮤니티에 쓴다.
- 모바일에서는 들여쓰기를 단계당 12–16px 로 줄이고 2단계 뒤부터 "답글 N개 더 보기"로 접는다.
- 용어를 하나로 정한다: 질문·답변·답글(댓글), 채택, 추천/투표. "upvote"는 "추천"으로 쓴다.
- 코드 안 한글 주석은 모노 폰트 폴백이 OS 기본 한글로 떨어진다. 모노 스택 뒤에 한글 산세리프를 둔다.
- 카피는 해요체: "답변을 채택했어요", "이 답변이 도움이 됐나요?", "답글 3개 더 보기".
