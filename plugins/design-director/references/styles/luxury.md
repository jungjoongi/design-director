# 럭셔리 (Luxury) — id: luxury

별칭: 고급스러운, 하이엔드, 프리미엄, 명품 느낌, refined, upscale
축: 밀도 1 · 온도 3 · 채도 1 · 대비 4 · 둥긂 1 · 장식 2
대표 레퍼런스: 하이엔드 패션·주얼리 하우스 사이트 — Chanel (chanel.com), Hermès (hermes.com) (정성, 미검증)

## 정의

절제와 희소성으로 말한다. 아주 큰 이미지와 아주 작은 글자, 넓은 여백, 고대비 세리프나 가는 산세리프, 흑·백·아이보리의
좁은 팔레트, 느린 움직임으로 "서두르지 않는 브랜드"를 표현한다. 정보를 덜 주는 것이 의도다 — 가격과 버튼이 조용하다.

"고급스럽게"라는 요청이 곧 luxury 는 아니다. 소프트웨어 제품의 "고급스러움"은 대개 minimal 이나 editorial 쪽 레버
(여백·대비·타이포 정밀도)로 푸는 편이 맞다. luxury 는 사진 품질이 받쳐 줄 때만 성립한다.

## 시그니처 무브

1. **이미지는 크게, 글자는 작게** — 이미지가 화면의 70–100%, 텍스트는 11–14px(한글은 12px 이상).
2. **라틴 대문자 라벨을 넓게 벌린다** — 11–13px, 자간 +0.1 ~ +0.2em. 브랜드명·카테고리에만.
3. **버튼을 조용하게** — 밑줄 텍스트 링크나 1px 테두리 버튼, 채움 색 없음.
4. **느리게 움직인다** — 이미지 전환 600–1000ms 크로스페이드, 스크롤 연출은 한 곳.
5. **팔레트를 흑백 + 하나로 좁힌다** — 유채색은 사진에만 두고 UI 는 무채색.

## 잘 맞는 곳 / 안 맞는 곳

- 잘 맞는 곳: 패션·주얼리·시계, 호텔·리조트, 고급 부동산, 갤러리, 와인·향수, 프리미엄 가구.
- 안 맞는 곳: 할인·가격 비교 커머스, 앱 기능 화면, 정보가 많은 서비스, 젊고 친근한 브랜드, 사진이 약한 제품.

## 흔한 실수

- "고급"을 검정 + 금색 그라데이션 글자로 푼다 — TY-3. 금색은 면적 1–2% 단색으로.
- 크림 바탕 + 세리프 + 테라코타 — CO-2
- 작은 글자를 옅은 회색으로 — CO-7. 글자가 작을수록 대비를 지킨다.
- "최고의 경험", "새로운 기준" 같은 과장 카피 — CP-4
- 한국어 제목 위에 영문 대문자 라벨 — KR-4. 라틴 라벨 관례가 한글 위에선 장식이 된다.

## 한국어 노트

- 한글엔 대문자가 없어 넓은 자간을 한글에 주면 띄엄띄엄 읽힌다. 한글 자간은 0 으로 두고(큰 명조 제목만 -0.02em 까지), 넓은 자간은 라틴 라벨에만 준다.
- 명조 display + 고딕 본문 페어링이 기본이다. 가는 명조는 큰 제목에서만 쓴다.
- 300 이하의 가는 한글은 작은 크기에서 사라진다. 한글 캡션은 12px 이상, 굵기 400 이상.
- 가격은 쉼표와 "원"만, 할인율을 소리치지 않는다.
