# 차분한 어드민 (Calm Admin) — id: admin-calm

별칭: 차분한 관리자 화면, 설정 콘솔, 운영자 콘솔, 백오피스, 여유 있는 어드민, SaaS 설정 화면, comfortable admin
축: 밀도 3 · 온도 3 · 채도 2 · 대비 3 · 둥긂 3 · 장식 1
대표 레퍼런스: 해외 B2B SaaS 의 설정·결제 관리 화면 계열, 국내 예약·CRM 솔루션의 운영자 콘솔 계열 (정성, 미검증)

## 정의

전문가가 아닌 운영자가 매일 여는 백오피스·설정 화면이다. 행을 넉넉하게(48–56px), 본문을 14–15px 로 두고,
옅은 중립 바탕 위에 1px 테두리 섹션 카드로 영역을 나눈다. 강조색은 차분한 하나만 쓰고 주 행동·선택 상태에만 칠한다.
화면이 "표 한 장"이 아니라 "정돈된 서랍장"처럼 읽혀야 한다. 빈 상태·로딩·저장 완료처럼 운영자가 불안해지는 순간을
먼저 설계한다.

이웃과의 차이: data-dense 는 표를 촘촘하게 쌓아 비교하게 하고, admin-calm 은 한 번에 한 가지 일을 끝내게 한다.
corporate-clean 은 마케팅 페이지까지 덮는 브랜드 시스템이고, admin-calm 은 로그인 뒤 화면 전용이라 그림자·사진이 거의 없다.
kr-admin-classic 은 검색 조건 박스와 회색 라벨 셀이 먼저 보이고, admin-calm 은 필터가 한 줄로 접혀 있다.

## 시그니처 무브

1. **넉넉한 행, 한 줄 구분** — 표 행 52px 전후, 셀 좌우 padding 16px, 1px 행 구분선. zebra 는 쓰지 않는다.
2. **섹션 카드 = 할 일 하나** — 설정 화면을 "기본 정보 / 알림 / 결제" 같은 카드로 나누고, 카드 머리에 제목 16–18px +
   설명 한 줄 13–14px, 카드 안쪽 24–32px. 저장 버튼은 카드 오른쪽 아래 같은 자리.
3. **강조색은 하나, 주 행동과 선택에만** — 화면당 채운 버튼 1개. 나머지는 테두리 버튼이나 텍스트 버튼.
4. **상태 3종을 화면에 그린다** — 빈 상태(무엇이 생기는지 + 주 행동 1개), skeleton 행, 저장 완료 토스트.
5. **설명을 붙인 폼** — 라벨 위·도움말 아래(13px), 좌측 라벨 열 200–240px 의 2열 설정 행도 좋다.

## 잘 맞는 곳 / 안 맞는 곳

- 잘 맞는 곳: 예약·주문 운영자 콘솔, 설정·계정·결제 관리, 소규모 사업자용 관리자, CRM, 고객지원 도구, 온보딩 뒤 첫 대시보드.
- 안 맞는 곳: 수백 행을 비교하는 분석 화면(data-dense), 실시간 관제(admin-console), 마케팅 랜딩.

## 흔한 실수

- 지표마다 같은 radius·그림자 카드를 끝없이 깐다 — LA-1. 카드는 섹션 단위로, 지표는 한 줄에 묶는다.
- 카드에 테두리·그림자·회색 채움을 동시에 — SH-5
- 차분함을 옅은 회색 글자로 낸다 — CO-7. 차분함은 채도에서 내고 명도 대비는 지킨다.
- 상태 배지·버튼·링크·차트에 색을 4개 넘게 — CO-5
- 기능 설명 자리에 옅은 둥근 사각 아이콘을 반복한다 — IC-2
- 모든 카드에 hover-lift — MO-2. 클릭할 수 있는 행만 배경색을 바꾼다.
- "~을 통해 관리할 수 있습니다" 같은 번역투 도움말 — KR-7

## 한국어 노트

- 비전문 운영자가 쓰므로 도움말은 해요체 짧은 문장으로 쓴다. "예약 확정 시 고객에게 문자가 가요."
- 버튼은 동사로 쓴다: "저장", "변경 사항 저장", "예약 확정". "확인"·"제출"은 피한다.
- 날짜는 `2026.10.15 (수)`, 시간은 `오후 2:30` 처럼 요일·오전/오후를 붙이면 전화 응대 중에도 읽힌다.
- 전화번호는 `010-1234-5678` 형식, 이름은 성+이름 그대로. 마스킹이 필요하면 `김*진`.
- 위험한 설정(영업 중지, 데이터 삭제)은 카드 맨 아래 "위험 구역"으로 떼고 빨간 테두리 버튼 하나만 둔다.
