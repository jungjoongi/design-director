# 한국형 게시판 (KR Classic Board) — id: kr-board-classic

별칭: 게시판형, 커뮤니티 게시판, 목록형 커뮤니티, 동호회 게시판, 카페 게시판 같은, 클래식 보드, classic board
축: 밀도 5 · 온도 2 · 채도 2 · 대비 3 · 둥긂 1 · 장식 1
대표 레퍼런스: 국내 대형 커뮤니티 게시판 계열, 오래된 동호회·카페형 게시판 계열 (정성, 미검증)

## 정의

글을 많이, 오래 읽는 사람을 위한 한 줄 행 목록이다. 번호·말머리·제목[댓글수]·글쓴이(레벨)·날짜·조회·추천 일곱 열을
36–44px 행에 촘촘히 놓고, 장식은 거의 없다. 사용자는 제목과 댓글 수·조회·추천을 한 번에 훑어 읽을 글을 고르고, 글을
다 읽으면 아래 이어지는 목록에서 다음 글로 넘어간다. 이 "훑기 → 고르기 → 읽기 → 다음 글" 속도가 곧 미학이다.

이웃과의 차이: data-dense 는 숫자·차트를 비교하는 대시보드이고, kr-board-classic 은 텍스트 제목을 고르는 목록이다.
숫자는 조회·추천 두 열뿐이고 위계는 제목 열이 쥔다. kr-local-feed 는 사진 카드로 가볍게 넘기고, forum-thread 는
글 하나의 답글 트리를 깊게 판다.

범위만 준다(이유는 `_index.md` §3).

| 목록 글자 | 제목 13–15px(400–500), 메타 12–13px | 단계가 좁다. 굵기보다 색으로 위계를 준다 |

| 아이콘 | 12–16px 선 아이콘, 새 글 `N` 배지(10–11px 굵게) | |

## 시그니처 무브

1. **제목 뒤에 댓글 수를 붙인다** — `제목 [12]`, 강조색 12–13px 굵게. 별도 열이 아니라 제목을 읽는 흐름 안에서 본다.
2. **공지를 tint 행으로 고정한다** — 1–3행, 번호 자리에 "공지", 배경 명도 96–98%, 제목 굵기 600.
3. **일곱 열을 36–44px 행에** — 번호·말머리·제목[댓글수]·글쓴이(레벨)·날짜(오늘은 `14:23`, 이전은 `10.13`)·조회·추천.
4. **목록 아래에 번호 페이지네이션 + 범위 검색** — `< 1 2 … 10 >` 10개 단위, 그 아래 [제목+내용 ▾] 입력 [검색].
5. **글 상세는 본문 아래 가운데 추천·비추천** — 48px 높이 버튼 한 쌍, 그 아래 스크랩·공유·신고 텍스트 버튼.
   댓글은 베스트 상단, 대댓글 1단계(24–32px 들여쓰기 + `ㄴ`), 그 뒤로 같은 게시판 목록이 이어진다.

## 잘 맞는 곳 / 안 맞는 곳

- 잘 맞는 곳: 텍스트 중심 커뮤니티, 동호회·카페, 사내 게시판, 공지·자료실, 질문 게시판, 팬 커뮤니티의 자유게시판.
- 안 맞는 곳: 사진이 주인공인 근황 피드, 첫 방문자를 설득하는 랜딩, 글이 하루 몇 개 안 되는 작은 커뮤니티(빈 목록이 커 보인다).

## 흔한 실수

- 목록을 둥근 카드 피드로 바꿔 한 화면에 글이 4–5개 — KR-6, LA-1
- 조회·추천 열을 "지저분해 보인다"며 뺀다 — KR-6
- 행마다 원형 아바타 40px — KR-6. 목록에서는 닉네임 + 레벨 텍스트만
- 메타를 옅은 회색 11px 로 — CO-7. 13px 목록에서는 바로 안 읽힌다
- 행 hover 에 그림자·lift, 목록 행 fade-up — MO-2, MO-1
- 숫자 열을 모노스페이스로 — TY-5. `tabular-nums` 로 충분하다
- 게시판 이름 위에 영문 대문자 eyebrow — KR-4

## 한국어 노트

- 13px 아래 한글은 획이 뭉친다. 목록 제목 13–15px, 메타 12px 를 하한으로 둔다(`korean-typography.md` §2).
- 날짜는 오늘 `14:23`, 올해 `10.13`, 지난해 `25.10.13`. 조회 1만 넘으면 `1.2만`.
- 레벨은 숫자 배지(`Lv.7`)나 짧은 등급명. 색을 쓰면 단계 3–4개까지만.
- 탭 이름은 서비스 성격에 맞게 하나: 베스트·인기글·HOT·개념글 중 하나만 쓴다.
- 카피는 해요체 짧은 동사형: "글쓰기", "검색", "삭제된 댓글이에요.", "차단한 사용자의 글이에요".
- 구조 세부는 `skills/direct/references/page-patterns/community.md` §2.1·§2.3·§2.4 가 이 문서보다 자세하다.
