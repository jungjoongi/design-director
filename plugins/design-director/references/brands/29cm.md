# 29CM — Reference Profile

## 1. 본질 (Essence)
취향으로 물건을 고르는 사람을 위해 화면의 90%를 화보 사진으로 덮고, UI 는 무채색 10–13px 글자와 1px 회색 선으로 물러나게 한 3단 매거진 피드와 할인율에만 쓰는 오렌지 #FF4800 하나로 잡지를 넘기다 사게 되는 편집숍 느낌을 만든다.

## 2. 스타일 분류 (Classification)
- primary: `kr-editorial-commerce` — 이미지 비중 90%, 콘텐츠 글자 10–13px, 중립 chroma 0 + 강조 #FF4800 1색(측정). 할인율·가격·배지·찜 수 같은 커머스 관례를 상품 행마다 유지한다
- secondary: `editorial` — 홈을 3단 매거진 지면처럼 짜고(브랜드 사진 단 + 기획 단 2개) 단 사이를 1px 세로선으로 나눈다. 단 세리프 제목·18px 이상 본문은 없다(editorial 범위 밖) — 글이 아니라 사진이 주인공이다
- treatments: 없음 — `backdrop-filter` 0, 그림자 0, 장식 그라데이션 없음(측정. 그라데이션 1개는 목록 끝 흰 페이드)
- 축: 밀도 4 · 온도 3 · 채도 2 · 대비 4 · 둥긂 1 · 장식 1 (스타일 기본 밀2 와 달리 첫 화면 빈 칸 12% 로 촘촘하다)

## 3. 무드 키워드 (Mood)
사진이 말하는 (photo-led) · 잡지를 넘기는 (magazine browsing) · 촘촘하지만 조용한 (dense but quiet) · 흑백 UI 위 오렌지 신호 하나 (monochrome UI, single orange signal) · 편집숍 큐레이션 (select-shop curation) · 날 선 모서리 (sharp-edged)

## 4. 시그니처 무브 (Signature Moves)
### 1. 화면을 사진으로 덮고 사진 사이 여백을 없앤다
- 수치: 이미지 비중 90%(측정), 첫 화면 빈 칸 12%(파생), 사진 radius 0(측정), max-width 없이 1440 풀폭(측정), 첫 줄 타일 사이 간격 0 + 1px 선(추정)
- 따라 하는 법: `.feed{display:grid;grid-template-columns:42fr 28fr 28fr;gap:0}` 사진은 `object-fit:cover;border-radius:0`. 화보급 사진이 없으면 사진 수를 줄이고 무브 2 의 카드 비중을 늘린다
### 2. 홈을 3단 매거진 피드로 짜고, 기획 하나에 상품 행 3개를 붙인다
- 수치: 단 폭 605 | 402 | 403px = 42/28/28%(추정), 스토리 카드 폭 355px · 제목 22px/700(측정), 상품 행 간격 약 92px · 썸네일 약 70px(추정). 가운데·오른쪽 단은 카드 높이가 달라 엇갈린다
- 따라 하는 법: 단별 flex column 두 개로 읽는 순서를 지킨다. 카드 = 3:2 사진 → 22px/700 제목 → 한 줄 설명 → `divide-y divide-[#DDD]` 상품 행 3개. 기획 단위가 먼저고, 모바일은 1단으로 접는다
### 3. 유채색은 할인율 숫자에만 쓴다
- 수치: accent #FF4800(측정, `--ruler-semantic-color-common-accent` 선언), 기타 유채색 0, 중립 10단계 chroma 0(측정). 찜 하트도 회색 선 아이콘이다
- 따라 하는 법: `.price-rate{color:#FF4800;font-weight:700}` 에만 쓰고 주 버튼·하트·배지는 #1F1F1F · #8A8A8A · #F0F0F0. 대비 3.4:1(파생)이라 접근성이 우선이면 #D53F00(4.63:1)로 내린다
### 4. 콘텐츠 글자를 10–22px 안에 가두고 위계는 굵기로 만든다

### 5. 그림자 없이 1px #DDDDDD 선과 radius 2–4px 로 면을 나눈다

## 8. 따라 할 때 Do / Don't
- Do: 사진을 가장자리까지 채우고 사진 사이 간격은 0, 경계는 1px 선으로만 둔다 — 무브 1
- Do: 기획 하나를 사진 + 22px 제목 + 한 줄 설명 + 상품 행 3개 카드로 묶는다 — 무브 2
- Do: 상품명 한 줄 말줄임, 할인율 → 가격 → 텍스트 배지 순서의 한국 커머스 관례를 지킨다. 한글 하한은 12px — 무브 4
- Don't: 상품을 radius 12 + 그림자 카드 4열 그리드로 바꾸지 않는다 — 무브 2·5, LA-1
- Don't: 오렌지를 CTA·탭·하트·배지로 넓히지 않는다 — 무브 3, CO-5
- Don't: 사진 없이 0 radius·hairline·빽빽한 단만 가져오지 않는다. 피드 카드마다 fade-up·hover-lift 도 넣지 않는다 — 무브 1, LA-4, MO-1, MO-2
- **흔한 오해**: 29CM ≠ 세리프 제목과 넓은 여백의 잡지. 에디토리얼 느낌은 사진 90%와 3단 피드에서 오고, 글자는 10–22px 산세리프에 자간 0, 첫 화면 빈 칸은 12% 로 촘촘하다
- **흔한 오해**: 29CM ≠ 오렌지 브랜드. #FF4800 은 할인율 숫자에만 있고, 버튼·하트·배지는 무채색이다(모바일 앱 설치 띠의 pill 하나만 예외)

## 부록: 화면 관찰 (Visual Read)
- 첫 화면은 위 약 214px 흰 헤더 아래를 사진 세 장이 꽉 채운다. 따뜻한 실내 인물 / 원색 일러스트 타이포 / 베이지 정물로 톤이 달라 잡지 표지처럼 다채롭다.
