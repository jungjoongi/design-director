웹훅이 실패해도
요청은 남아요

relay는 들어온 웹훅을 큐에 쌓고, 받는 쪽이 응답하지 않으면 간격을 늘려 가며 다시 보내요. 로컬에서도 CLI 한 줄로 같은 요청을 받아 볼 수 있어요.

계정 만들기문서 읽기
$npm i -g @relay/cli
relay listen
$ relay listen --forward localhost:3000/webhooks ok 엔드포인트 https://in.relay.dev/r/7f3k localhost:3000 으로 전달하는 중 14:02:11 POST /webhooks/payments 200 41ms 14:02:13 POST /webhooks/orders 503 재시도 1/5, 4초 뒤 14:02:17 POST /webhooks/orders 200 38ms 14:02:20 POST /webhooks/payments 200 45ms 14:02:26 POST /webhooks/refunds 200 52ms
