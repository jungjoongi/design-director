useEffect 안에서 fetch가 두 번 호출돼요. 개발 모드에서만 그런가요?

해결됨하하루한커밋 평판 312질문 2시간 전조회 1,284
24

마운트할 때 목록을 불러오는데 네트워크 탭을 보면 /api/posts 요청이 항상 두 번 나가요. 의존성 배열은 비워 뒀어요.

useEffect(() => { getPosts().then(setPosts); }, []); // 요청이 두 번 나가요

React 18의 StrictMode는 개발 모드에서 effect를 일부러 마운트 → 정리 → 다시 마운트해요. 정리 함수에서 요청을 취소하면 한 번만 반영되고, 운영 빌드에서는 처음부터 한 번만 실행돼요.

useEffect(() => {
  const ctrl = new AbortController();
  getPosts(ctrl.signal).then(setPosts);
  return () => ctrl.abort(); // 다시 마운트되기 전에 첫 요청 취소
}, []);
