# 모아노트 랜딩 페이지

모아노트는 회의 녹음을 올리면 결정 사항·할 일·다음 안건으로 요약해 주는 팀 도구다. 5–20명 규모 팀의 리더가
매주 회의록을 정리하는 시간을 줄이려고 만들었다. 이 저장소는 모아노트의 마케팅 랜딩 페이지(`index.html` 한 장)다.

## 실행

빌드 단계가 없다. 스타일은 Tailwind CSS v4 브라우저 빌드를 CDN 으로 불러와 페이지 안에서 컴파일한다.

```bash
npm run dev   # python3 -m http.server 4173
```

브라우저에서 http://localhost:4173/ 을 연다.

## 파일

- `index.html` — 페이지 전체 (히어로, 고객 로고, 기능, 사용 방법, 후기, 요금제, FAQ, CTA)
