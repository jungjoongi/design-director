# 모아노트 커뮤니티

모아노트 사용자 커뮤니티의 게시판 화면이다. 모아노트는 회의 녹음을 요약해 주는 팀 도구이고, 이 커뮤니티에서는
5–20명 팀을 이끄는 리더와 팀원들이 회의록 정리 팁을 나누고 사용법을 묻는다. 지금은 게시판 목록과 글 상세 두 화면만 있다.

## 실행

빌드 단계가 없는 정적 페이지다.

```bash
npm run dev   # python3 -m http.server 4173
```

- 목록: http://localhost:4173/
- 글 상세: http://localhost:4173/post.html

## 파일

- `index.html` — 자유게시판 목록
- `post.html` — 글 상세와 댓글
- `styles.css` — 두 화면이 같이 쓰는 스타일
