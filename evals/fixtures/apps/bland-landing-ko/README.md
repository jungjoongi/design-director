# 모아노트 랜딩 페이지

모아노트는 회의 녹음을 올리면 결정 사항·할 일·다음 안건으로 요약해 주는 팀 도구다. 5–20명 규모 팀의 리더가
매주 회의록을 정리하는 시간을 줄이려고 만들었다. 이 저장소는 모아노트의 랜딩 페이지이고, 지금 목표는 14일 무료 체험
신청을 받는 것이다.

## 실행

빌드 단계가 없는 정적 페이지다.

```bash
npm run dev   # python3 -m http.server 4173
```

브라우저에서 http://localhost:4173/ 을 연다.

## 파일

- `index.html` — 페이지 마크업 (히어로, 기능, 사용 방법, 요금, 자주 묻는 질문, CTA, 푸터)
- `styles.css` — 스타일 전체. 색·글꼴은 맨 위 `:root` 변수에 있다
