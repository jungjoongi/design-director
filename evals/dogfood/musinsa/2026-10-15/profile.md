## 4. 시그니처 무브 (Signature Moves)

### 1. 글자를 13px 로 줄이고 위계는 굵기와 빨강으로만 만든다
- 관찰: 모든 상품 카드와 모듈 제목(slices 05–09). 페이지 HTML 글자 중 가장 큰 것이 히어로 배너 위 20px 이고, 더 큰 글자는 모두 배너 이미지 안에 있다
- 수치: body 13px / 1.38(측정 ×81) · small 12px / 1.42(측정) · h1 20px / 600(측정). 가장 큰 글자 : 본문 = 1.54 : 1(파생). 단계 11 12 13 14 16 20(파생)
- 기본값과의 차이: 본문 16 / 1.5 보다 3px 작고, 헤드라인 48px 대비 절반 아래. 크기 대비를 거의 포기하고 굵기(400 / 600–700)와 색(검정 / #666 / 빨강)으로 위계를 만든다
- 따라 하는 법: `--fs-meta: 12px; --fs-body: 13px; --fs-title: 18px; --fs-hero: 20px;` 브랜드명 `12px/700`, 상품명 `13px/400` + `line-clamp-2`, 가격 `13px/700`. 한글 행간은 1.4–1.5 로 둔다(무신사의 1.38 은 KR-5 경계)
- 깨지는 경우: 상세 설명·후기처럼 긴 글에 쓰면 읽기 힘들다 → 목록·카드에만 쓰고 상세 본문은 15–16px / 1.6

### 2. UI 를 무채색으로 두고 빨강은 할인율에만 쓴다
- 관찰: 모든 상품 카드 가격 줄(slices 05–09). 버튼·링크·아이콘·하트는 검정·회색이다
- 수치: 유채색 글자의 94.5% 가 #F5415F(측정), 중립 램프 10단계 #000000 → #FFFFFF(측정), monochrome 예(측정), #F5415F / 흰 바탕 대비 3.6 : 1(파생)
- 기본값과의 차이: 흔한 커머스는 브랜드색을 CTA·배지·링크·아이콘에 모두 칠해 사진과 경쟁한다
- 따라 하는 법: `--sale: #E0263F;` (흰 바탕 4.6 : 1 로 보정) `.price-rate { color: var(--sale); font-weight: 700; } .price { color: #000; font-weight: 700; }` 같은 줄에 '할인율 → 판매가' 순서
- 깨지는 경우: 오류색과 겹친다 → 오류는 아이콘 + 문구로 구분한다. 할인이 없는 상품은 빨강 없이 가격만 검정으로 둔다

### 3. 상품 사진을 radius 0·간격 0 레일로 붙이고 화면 끝에서 자른다
- 관찰: 모든 product-grid 레일(slices 05–09)과 히어로 배너 3장(desktop.png)
- 수치: 카드 폭 260px · padding 0 · radius 0(측정), 사진 260 × 312 = 5 : 6(추정, slice 06 픽셀), 레일은 x16 에서 시작해 1440 에서 잘려 5.5장이 보인다(추정), 히어로 배너 480px × 3장 gap 0(측정)
- 기본값과의 차이: 흔한 상품 그리드는 4열 · gap 16–24 · radius 8–12 · 카드 그림자. 여기는 사진끼리 맞닿아 하나의 띠로 읽힌다
- 따라 하는 법: `.rail { display: grid; grid-auto-flow: column; grid-auto-columns: 260px; gap: 0; overflow-x: auto; scroll-snap-type: x mandatory; margin-right: calc(50% - 50vw); } .rail img { aspect-ratio: 5 / 6; object-fit: cover; border-radius: 0; }`
- 깨지는 경우: 사진 배경색이 제각각이면 맞닿은 경계가 지저분하다 → 누끼 컷 배경을 #F5F5F5 계열로 맞추거나 gap 2px. 사진 품질이 약한 상품군이면 성립하지 않는다

### 4. 머리를 거의 검정 띠 하나로 묶고 이벤트 색은 그 안에만 둔다
- 관찰: desktop.png y0–192. 내비·검색·탭 줄이 한 면이고, 탭 줄의 기획전 라벨 6개만 색 글자다. 스크롤하면 검색이 빠지고 약 104px 띠가 고정된다(slice 05)
- 수치: #1A1B1F(측정), 내비 56px sticky(측정, `--layout-header-top: 56px` 선언), 콘텐츠 시작 y192(측정), 이벤트 라벨 #3A6EFF · #A97BFF · #F19053 · #F7E74B 각 0.5–1%(측정)
- 기본값과의 차이: 흔한 커머스 헤더는 흰 바탕 + 아래 1px 선이다. 여기는 페이지에서 유일한 어두운 면이 위를 눌러 준다
- 따라 하는 법: `header { background: #1A1B1F; color: #fff; position: sticky; top: 0; }` 탭 줄 기획전 라벨만 `color: var(--event-<id>)`, 두 줄 12px/700
- 깨지는 경우: 본문까지 어두워지면 사진이 묻힌다 → 어두운 면은 헤더 하나, 본문은 #F5F5F5 / #FFFFFF. 이벤트 색이 헤더 밖 버튼으로 새면 무브 2 가 깨진다

### 5. 기획전마다 풀폭 색 띠로 레일 흐름을 끊는다
- 관찰: overview.jpg 01·07·08 — 분홍(뷰티 기획전), 회갈색(신발 기획전), 노랑(중고 거래) 띠. 나머지 모듈은 #F5F5F5 바탕 위 흰 면이다
- 수치: 띠 3개 / 페이지 17,569px(추정, 샘플 슬라이스 기준), 노랑 띠 약 #F5E54A(추정), 바탕 #F5F5F5 43% · 모듈 #FFFFFF 50%(측정), 그림자 0개(측정)
- 기본값과의 차이: 흔한 랜딩은 배경 교차가 없거나 매 섹션 교차한다. 여기는 흰 레일이 길게 이어지다 기획전에서만 색이 바뀐다
- 따라 하는 법: `.band { background: var(--event-bg); padding-block: 24px 32px; }` 띠 안은 제목 + 남은 시간 + 로고 칩 필터 + 같은 레일 컴포넌트를 그대로 쓴다
- 깨지는 경우: 띠가 매 모듈 오면 축제가 아니라 소음이다 → 레일 3–4개마다 1개, 띠 색 하나는 기획전 하나만 쓴다

## 8. 따라 할 때 Do / Don't

Do
- 목록 글자는 12 / 13px 두 크기로 두고 위계는 굵기(400 / 700)와 색(검정 / #666 / 빨강)으로 만든다 (무브 1)
- 상품 사진은 5:6 하나로 통일하고 radius 0 · gap 0 레일로 붙여 오른쪽 끝에서 반 장 잘리게 둔다 (무브 3)
- 유채색은 할인율 하나만, 흰 바탕에서 4.5:1 을 넘게 #E0263F 정도로 진하게 보정해 쓴다 (무브 2)
- 어두운 면은 sticky 헤더 하나(#1A1B1F)로 끝내고 본문은 #F5F5F5 바탕 + 흰 모듈로 단계만 둔다 (무브 4)
- 기획전은 레일 3–4개마다 풀폭 색 띠 하나로, 안의 레일은 같은 컴포넌트를 재사용한다 (무브 5)
- 한글 상품명은 `word-break: keep-all` + `line-clamp: 2` 로 끊는다 — 무신사는 keep-all 4% 라 낱말 중간이 끊긴다

Don't
- 상품 카드에 radius 12 + 그림자를 넣어 SaaS 카드처럼 만들지 않는다 — 무브 3, LA-1, SH-2
- 빨강을 버튼·배지·제목으로 넓히거나 브랜드색 CTA 를 추가하지 않는다 — 무브 2, CO-5
- 헤더의 이벤트 색을 본문 버튼·아이콘으로 퍼뜨리지 않는다 — 무브 4, CO-5
- 기획전 띠를 그라데이션 블롭 배경으로 바꾸지 않는다 — 무브 5, CO-4
- 메인에 정가 취소선이 없다고 목록·상세에서 할인율·정가·리뷰 수 같은 커머스 관례를 빼지 않는다 — KR-6
- 13px 본문을 상세 설명·후기 같은 긴 글로 넓히지 않는다. 한글 행간도 1.4 아래로 내리지 않는다 — 무브 1, KR-5

## 부록: 화면 관찰 (Visual Read)

- 첫 화면 위 192px 는 거의 검정(#1A1B1F) 띠 하나다. 1단 내비(서비스 탭 + 유틸 링크 + 테두리 로그인 버튼), 흰 검색창, 탭 줄이

- 히어로 아래로 특전 타일(140×60 안팎, 옅은 회색·파스텔 면, 작은 상품 컷 + 12px 라벨)이 9열 2줄, 서비스 바로가기 pill 이 한 줄.
- 본문은 #F5F5F5 바탕 위에 흰 모듈이 이어지는 구조다. 모듈마다 왼쪽 위 굵은 제목(약 18px) + 오른쪽 '…' 밑줄 링크,
