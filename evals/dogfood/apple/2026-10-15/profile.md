# Apple 대한민국 — Reference Profile

## 1. 본질 (Essence)

제품을 고르러 온 사람을 위해, 12px 흰 틈으로만 나뉜 검정·연회색 타일 벽에 타일마다 제품 렌더 하나를 올리고 파랑은 버튼에만
남겨서 '진열장 앞에 선' 느낌을 만든다.

## 2. 스타일 분류 (Classification)

- **primary `minimal`** — UI 는 무채색 램프 10단계 + 강조 파랑 1색(버튼·링크에만), 그림자 0개, 장식 요소 없음,
  첫 화면 빈 칸 93%(파생), 첫 화면 메시지 1개 + CTA 2개.
- **secondary `luxury`** — 레버 일부만 가져온다: 순검정 배경 위 스튜디오 조명 제품 렌더, 이미지 면적 177%(측정),
  타일 radius 0, 버튼이 작고 조용하다(44px, 굵기 400). 세리프와 넓은 자간 대문자, 느린 모션은 **없다**.
- **treatment `glassmorphism`** — 내비 한 곳에만: `#1D1D1FCC` 반투명 + backdrop blur(측정, blur 요소 1개). 카드·타일에는 쓰지 않는다.
- 카탈로그와의 차이: minimal 의 "섹션 여백 120–200px" 대신 **섹션 여백 0 + 타일 틈 12px** 로 구획한다. 여백은 타일 *안*에 있다.
- 축: 밀도 1 · 온도 2 · 채도 2 · 대비 5 · 둥긂 3 · 장식 1
  (채도: UI 는 1, 제품 사진이 색을 가져와 2. 둥긂: 타일 0 + 버튼 pill 100% 의 두 단계라 중간값 3.)

## 4. 시그니처 무브 (Signature Moves)

### 1. 페이지를 제품 타일로 쌓고 12px 흰 틈으로만 나눈다
- 관찰: overview.jpg 전체, desktop.png y736–748 의 흰 띠. 섹션 경계에 선·그림자·모서리가 없다
- 수치: 섹션 상하 여백 0px(측정), 타일 틈 12px(파생: 반폭 타일 702px(측정) × 2 + 12 × 3 = 1440), 풀폭 타일 높이 692px
  (선언 `--hero-content-height`), 반폭 타일 높이 580px(파생), 타일 radius 0·그림자 0(측정)
- 기본값과의 차이: 기본은 섹션 여백 64–96px + 1200px 컨테이너 안 radius 8·shadow-md 카드. 여기선 여백 0, 풀블리드, 모서리 0,
  그림자 0 — 방향이 반대다
- 따라 하는 법:
  ```css
  .tiles { display: grid; grid-template-columns: repeat(2, 1fr); gap: 12px; padding: 0 12px 12px; }
  .tile--full { grid-column: 1 / -1; margin-inline: -12px; min-height: 692px; }
  .tile { border-radius: 0; box-shadow: none; overflow: hidden; }
  @media (max-width: 734px) { .tiles { grid-template-columns: 1fr; padding-inline: 0; } }
  ```
- 깨지는 경우: 타일마다 다른 제품 이미지가 없으면 같은 상자가 반복될 뿐이다(LA-3). 보여줄 대상이 3개 이하면 타일 벽보다
  minimal 의 섹션 여백(120px+) 쪽이 낫다

### 2. 타일 배경을 순검정과 #F5F5F7 로 번갈아 명도로 리듬을 만든다
- 관찰: overview.jpg 01–04 — 풀폭 3장 검정 → 회색 → 검정, 반폭 행은 (회색|검정) → (사진|사진) → (검정|회색)으로 엇갈린다
- 수치: 배경 면적 흰 47% · #F5F5F7 27% · #000000 26%(측정). 다크는 `#111` 이 아니라 순검정 `#000`(측정)
- 기본값과의 차이: 기본은 흰 배경 연속에 가끔 옅은 회색 섹션 하나. 여기선 타일마다 명도가 뒤집힌다. 구획을 여백이 아니라 배경이 맡는다
- 따라 하는 법: `--tile-dark: #000; --tile-light: #F5F5F7;` 다크 타일은 글자 흰색 계열, 테두리 버튼 `#2997FF`.
  체커보드가 되도록 2열 행에서는 좌우를 엇갈린다
- 깨지는 경우: 제품 이미지가 타일 배경과 같은 색 위에서 찍혀(또는 투명 배경이어서) 배경에 녹아야 한다. 흰 박스 사진을
  검정 타일에 올리면 사각형이 떠 보인다

### 3. 모든 타일을 같은 가운데 스택으로 연다
- 관찰: 타일 9장 모두 — 제품명 → 태그라인 1줄 → (선택) 회색 날짜 1줄 → pill 버튼 2개 → 아래로 제품 렌더
- 수치: 제품명 56px/600/1.18(풀폭, 측정) · 40px/600/1.1(반폭, 측정), 태그라인 28px/400/1.25(측정), 타일 상단 안쪽 53px(측정),
  제품명:태그라인 = 2:1 크기 + 600:400 굵기 대비
- 기본값과의 차이: 기본 히어로는 h1 64–72px+ 왼쪽 정렬·긴 리드 문단. 여기선 제품명이 생각보다 작고(56px), 리드는 한 줄,
  모든 타일이 같은 문법이다
- 따라 하는 법:
  ```css
  .tile { display: flex; flex-direction: column; align-items: center; text-align: center; padding-top: 53px; }
  .tile h2 { font: 600 clamp(2rem, 1.443rem + 2.286vw, 3.5rem)/1.18 var(--font-sans); letter-spacing: 0; }
  .tile h3 { font: 600 40px/1.1 var(--font-sans); }
  .tile .tagline { font: 400 28px/1.25 var(--font-sans); margin-top: 6px; }
  ```
- 깨지는 경우: 같은 골격의 반복은 타일마다 이미지가 다를 때만 산다(LA-3). 설명 문단을 넣으면 긴 본문 가운데 정렬(TY-6)이 된다 —
  태그라인은 한 줄, 20자 안팎

### 4. 파랑은 누를 것에만, 작은 pill 로 쓴다
- 관찰: 모든 타일의 버튼 쌍, 본문 링크. 제목·아이콘·배경에는 파랑이 없다
- 수치: 채운 버튼 `#0071E3`, 라이트 위 테두리 버튼·링크 `#0066CC`, 다크 위 테두리 버튼 `#2997FF`(측정). 높이 44px · 패딩 21px ·
  pill · 17px/400(측정), 반폭 타일은 36px · 패딩 15px(측정). 테두리 1px. 흰 글자/파랑 4.7:1(파생)
- 기본값과의 차이: 기본은 파랑·보라 + 그라데이션, 버튼 굵기 600, radius 8. 여기선 그라데이션 0, 굵기 400, pill, 배경 명도에 따라
  파랑을 두 단계로 바꾼다
- 따라 하는 법:
  ```css
  .btn { height: 44px; padding: 0 21px; border-radius: 980px; font: 400 17px/1 var(--font-sans); }
  .btn--primary { background: #0071E3; color: #fff; }
  .btn--secondary { border: 1px solid currentColor; color: #0066CC; }
  .tile--dark .btn--secondary { color: #2997FF; }
  .tile--half .btn { height: 36px; padding: 0 15px; }
  ```
- 깨지는 경우: 브랜드색이 파랑이 아니면 '누를 것' 색 하나만 바꾼다. 파랑을 제목·아이콘·면에 쓰면 무브가 무너진다.
  버튼 2개는 실제로 두 행동(…)이 있을 때만 — 습관적 쌍이면 CP-6

### 5. 제품 렌더가 색을 독점하게 하고 타일 아래쪽을 채운다
- 관찰: desktop.png 히어로, slice 03·04 반폭 타일. 렌더가 타일 하단에 붙거나 잘려 나간다
- 수치: 이미지 면적 177%(측정, 겹침 포함), UI 는 무채색 램프 10단계 + 강조 1색(측정), 글자 그라데이션 0(측정),
  렌더가 타일 높이의 약 50–60%(추정)
- 기본값과의 차이: 기본은 아이콘 + 제목 + 설명 3열 카드, 일러스트, 히어로 뒤 그라데이션 블롭. 여기선 사진 한 장이 타일의 증거다
- 따라 하는 법: `.tile img { margin-top: auto; width: min(100%, 980px); object-fit: contain; }` 이미지를 타일 하단에 붙이고
  배경색과 같은 배경에서 찍은(또는 투명) 렌더를 쓴다
- 깨지는 경우: 실물 품질의 제품 이미지·실제 화면이 없으면 성립하지 않는다 → 무브 5 를 버리고 minimal 의 여백 무브로 간다.
  AI 생성 렌더면 IC-5, 의미 없는 3D 형태면 IC-3

## 8. 따라 할 때 Do / Don't

**Do**
- 섹션 여백 대신 타일 틈 12px 로 페이지를 나누고, 타일은 radius 0·그림자 0 으로 둔다 (무브 1)

**Don't**
- 타일에 radius 16·그림자·1px 테두리를 얹지 않는다 — 무브 1, LA-1·SH-5
- 타일 사이를 64–96px 여백으로 벌리지 않는다. 틈은 12px 하나다 — 무브 1

## 부록: 화면 관찰 (Visual Read)

- **페이지 = 타일 벽.** 홈 전체가 "제품 1개 = 타일 1장"으로 쌓인다. 위 3장은 화면 폭을 꽉 채운 풀폭 타일(692px 높이),
  그 아래 6장은 2열 반폭 타일(702px 폭)이다. 타일 사이·반폭 행의 화면 가장자리는 모두 같은 12px 흰 틈으로만 갈린다

- **명도로 리듬을 만든다.** 타일 배경이 검정(#000) ↔ 밝은 회색(#F5F5F7) ↔ 연한 하늘색 사진 배경으로 교차한다. 실눈으로 보면

- **타일 안 문법이 하나다.** 위에서부터 가운데 정렬: 제품명(크고 굵게) → 한 줄 태그라인(얇고 절반 크기) → (선택) 회색 날짜 한 줄
